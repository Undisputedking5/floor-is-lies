# Floor is Lies

A 2D troll / rage-platformer that runs in the browser. Reach the glowing door. The floor, the spikes, gravity and the door itself are all lying to you.

## Play
Open `index.html` in any browser. No build step or dependencies.

## Controls
- Left / Right or A / D: move
- Space / Up / W: jump (hold for height)
- R: retry (counts as a death)
- M: mute music
- On-screen buttons on touch devices

## Levels
1. **Just Walk Right**: falling floor, pop-up spike
2. **Trust Issues**: crumbling platform, runaway door
3. **Up Is Optional**: gravity flips, ceiling spike, ironic checkpoint
4. **Personal Space**: ceiling crusher, invisible block
5. **The Exit Is Lying**: the door is a monster

Built with plain HTML5 Canvas and the Web Audio API.
